## ✨ About the Project

**VELORA** is a fashion storefront concept designed around a clean editorial look, neutral colors, bold typography, and a smooth shopping experience. It showcases clothing collections, accessories, and seasonal style inspiration in a responsive interface.

This project is ideal for practicing front-end development and can be extended into a full e-commerce application.

## 🛍️ Features

- **Editorial hero section** with a seasonal campaign and call-to-action
- **Shop by category** — Women, Men, and Accessories
- **Product collection grid** with product images, prices, and labels
- **Category filters** to browse products by collection
- **Quick-add shopping bag** with a live item count and confirmation message
- **Wishlist buttons** to save or unsave items visually
- **Product search** for finding items in the displayed collection
- **Newsletter signup UI** with basic form validation and demo confirmation
- **Responsive layout** for desktop, tablet, and mobile screens
- **Subtle animations and hover effects** for a polished interface
- **Accessible touches** such as descriptive image alt text and form labels

## 🧰 Built With

- **HTML5** — semantic page structure

- **Vanilla JavaScript** — product filtering, search, wishlist, shopping bag, and newsletter interactions
- **Google Fonts** — typography
- **Unsplash** — remote fashion photography

## 🚀 Run Locally

### Option 1 — Open in a browser

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

### Option 2 — Use VS Code + Live Server

1. Open the folder in Visual Studio Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

> **Tip:** An internet connection is needed to load the remote images and Google Fonts.

## 🧪 Try These Interactions

1. Use the category buttons to filter the product collection.
2. Click a heart icon to toggle a product's wishlist state.
3. Click **Quick add** to add a product to the demo shopping bag.
4. Click the search icon to search products currently shown in the collection.
5. Enter an email address in the newsletter section to test the form interaction.
6. Resize the browser or open the site on your phone to test responsiveness.

## ⚠️ Current Limitations

This is a **front-end demo**, not a production e-commerce store.

- Cart contents are kept only in the current page session
- Newsletter signup displays a demo confirmation; it does not subscribe an email to a mailing list
- No payment processing, backend, inventory, or user accounts are connected
- Product photography is loaded from external image URLs and may require internet access
